## 4. 组间休息（改进）

### 4.1 现有问题

现在 `restLeft` 是页面级单一倒计时，所有动作共用一个时长。原版是**每个动作独立 `restTime`**。

### 4.2 改法

1. `TrainMove` 加 `restTime: number`（默认 90 秒），见 [01-数据模型.md](01-数据模型.md)
2. `toggleSet(mi, si)` 勾选完成时，取 `record.moves[mi].restTime` 启动倒计时
3. 倒计时条显示当前动作名：

```vue
<view v-if="restLeft > 0" class="rest-bar">
	<view class="rest-left">
		<text class="rest-label">{{restMoveName}} · 组间休息</text>
		<text class="rest-time">{{restText}}</text>
	</view>
	<view class="rest-skip" @tap="skipRest"><text class="rest-skip-text">跳过</text></view>
</view>
```

## 6. 完成训练

现有 `finish()` 直接保存。原版有二次确认：「确定要结束本次训练吗？」+「本次训练共 N 个动作，M 组」。

**建议加确认弹窗**（`uni.showModal`）：

```ts
function finish() {
	uni.showModal({
		title: '结束训练',
		content: '本次训练共 ' + moveCount.value.toString() + ' 个动作，' + setCount.value.toString() + ' 组',
		confirmText: '完成',
		success: (res) => {
			if (res.confirm) { doFinish() }
		}
	})
}
```

⚠️ 空训练（0 组完成）时提示「没有完成的组，是否保留记录？」。

## 7. 输入框的 UTS 细节

现有写法是对的，保持：

```vue
<input class="set-input" type="digit"
	:value="st.weight > 0 ? st.weight.toString() : ''"
	placeholder="0" placeholder-style="color:#C7C7CC"
	@input="onWeightInput($event as UniInputEvent, mi, si)" />
```

⚠️ 三个坑：

1. **必须用 `:value` 而不是 `v-model`** —— `v-model` 在数字输入框上会把空串转成 0，导致删不掉数字。
2. **必须 `$event as UniInputEvent`** —— UTS 强类型，不转换编译不过。
3. **`type="digit"`** 才能出小数点键盘。`type="number"` 出的是整数键盘。
