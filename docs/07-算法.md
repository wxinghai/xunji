# 07 算法

所有公式从 APK 模块 `471`（`e.oneRM` / `e.Calulator` / `e.CaculateOneMoveVolume` / `e.CaculateVolume`）原码抄出。

## 1. 容量（Volume）

### 1.1 原码

```js
// 模块 471
var l = function(t) {
  var u = t.reps, l = t.weight, f = t.unit, v = t.type, c = t.move, h = t.dropset,
      y = t.exetype, M = t.left_weight, w = void 0 === M ? 0 : M;
  if (c && c.cardio) return 0;
  var F = l, k = "kg" === f ? 1 : .4532;
  if ("自重" !== v && "times" !== y) { k = k } else { k = 1 }
  if ("有氧" === v) { k = 0 }
  var S = s(u),
      _ = s(F) + (c && !0 === c.singleSide ? s(w) : 0);
  if (y === MovementType.plus_weight.key) { _ = s(c.currentWeight) + s(F) }
  _ = s(_);
  var E = p(S * _ * k);
  // 递减组累加
  if (h) h.forEach(function(t) {
    var o = s(t.reps), n = s(t.weight) + (c && !0 === c.singleSide ? s(t.left_weight) : 0);
    if ("自重" === v) { n = 1; k = 1 }
    n = s(n);
    var u = p(o * n * k);
    if (u) { E += u }
  });
  return p(E || 0)
}
```

其中：
- `s(x)` = `parseFloat(x)`，非有限数返回 0，负数返回 0
- `p(x)` = 保留 1 位小数：`parseFloat((Math.round(10 * x) / 10).toFixed(1))`

### 1.2 单组容量公式

```
单组容量 = reps × weight × unitFactor
```

| 条件 | unitFactor |
|---|---|
| `unit == 'kg'` | 1 |
| `unit == 'lbs'` | 0.4532 |
| `exetype == 'times'`（计次训练） | 1 |
| `cate == '自重'`（自重动作） | 1 |
| `cate == '有氧'` | 0（整组不计） |

### 1.3 单动作容量

```js
CaculateOneMoveVolume(t) {
  // t.sets 为普通动作
  t.sets.forEach(n => {
    if (n.setType !== "热" && n.done) {
      let p = t.currentWeight
      if (n.unit === 'lbs') { p = parseFloat(p) / .4532 }
      const v = (exetype === MovementType.help.key)   // 辅助训练
      u += l({ reps: n.reps,
               weight: f + parseFloat(v ? parseFloat(p) - parseFloat(n.weight) : n.weight),
               unit: n.unit, type: t.type, dropset: n.dropset,
               exetype: exetype, move: t, left_weight: n.left_weight })
    }
  })
  if (t.oneSide) { u *= 2 }
  return p(u)
}
```

**四条关键规则**：
1. `setType === "热"` 的组**不参与**容量计算
2. 只算 `done === true` 的组
3. `help`（辅助训练）类型：`weight = 体重 - 辅助重量`
4. `oneSide`（单侧动作）：整个动作容量 ×2

### 1.4 本项目实现（简化）

```ts
/** 单组容量，未完成/热身组返回 0 */
export function setVolume(set : TrainSet, unitFactor : number) : number {
	if (!set.done) { return 0 }
	if (set.setType == '热') { return 0 }
	const w = set.weight
	const r = set.reps
	if (w <= 0 || r <= 0) { return 0 }
	return w * r * unitFactor
}

/** 单位换算系数 */
export function unitFactor(unit : string) : number {
	return unit == 'lbs' ? 0.4532 : 1
}

/** 单动作总容量 */
export function moveVolume(mv : TrainMove) : number {
	let sum = 0
	for (let i = 0; i < mv.sets.length; i++) {
		const s = mv.sets[i]
		const f = unitFactor(s.unit == null ? 'kg' : s.unit)
		sum += setVolume(s, f)
	}
	if (mv.oneSide) { sum = sum * 2 }
	return round1(sum)
}

/** 整条训练容量 */
export function recordVolume(rec : TrainRecord) : number {
	let sum = 0
	for (let i = 0; i < rec.moves.length; i++) {
		sum += moveVolume(rec.moves[i])
	}
	return round1(sum)
}

export function round1(v : number) : number {
	return Math.round(v * 10) / 10
}
```

**注意**：现有 `common/storage.uts` 的 `recordVolume()` 是 `total += s.weight * s.reps`，**没有排除热身组、没有单位换算**。用它替换。

## 2. 1RM 估算

### 2.1 原码

```js
e.oneRM = function(t, o) {
  var n = parseFloat(t) * (1 + .0333 * parseFloat(o));
  return n ? n.toFixed(1) : 0
}
```

即 **Epley 公式**：

```
1RM = weight × (1 + 0.0333 × reps)
```

返回**字符串**，保留 1 位小数；`weight` 为 0 时返回数字 `0`。

### 2.2 实现

```ts
export function oneRM(weight : number, reps : number) : number {
	if (weight <= 0 || reps <= 0) { return 0 }
	return Math.round(weight * (1 + 0.0333 * reps) * 10) / 10
}
```

⚠️ `reps = 1` 时应直接返回 `weight`（公式给出 `weight × 1.0333`，偏高）。原版**没有做这个特判**，照抄原版即可。

## 3. 单位换算

```js
k = "kg" === f ? 1 : .4532        // lbs → kg
p = parseFloat(p) / .4532         // kg → lbs
```

| 方向 | 公式 |
|---|---|
| lbs → kg | `lbs × 0.4532` |
| kg → lbs | `kg / 0.4532` |

⚠️ 不是 `0.45359237`，原版用的就是 **0.4532**。差 0.09%，但为了和原版数字完全一致，用 0.4532。

```ts
export function lbsToKg(lbs : number) : number { return lbs * 0.4532 }
export function kgToLbs(kg : number) : number { return kg / 0.4532 }
```

## 4. 训练完成度

模块 6209 的 `calculatePercent(movement)`：

```
percent = Math.floor(已完成组数 / 总组数 × 100)
```

⚠️ **热身组也计入总组数**（与容量算法相反）。

```ts
export function trainPercent(rec : TrainRecord) : number {
	let total = 0
	let done = 0
	for (let i = 0; i < rec.moves.length; i++) {
		const sets = rec.moves[i].sets
		total += sets.length
		for (let j = 0; j < sets.length; j++) {
			if (sets[j].done) { done += 1 }
		}
	}
	if (total == 0) { return 0 }
	return Math.floor(done * 100 / total)
}
```

## 5. 训练时长

```js
x = parseInt((parseInt(end) - parseInt(start)) / 1000)   // 秒
x = x > 0 ? x : 0
```

显示格式 `H:MM`：

```js
c = Math.floor(u / 3600)
f = Math.floor(u % 3600 / 60)
if (f < 10) f = "0" + f
return c + ":" + f
```

⚠️ 小时位**不补零**（显示 `0:05` 而不是 `00:05`）。分钟位补零。

```ts
export function trainDuration(rec : TrainRecord) : number {
	if (rec.start <= 0 || rec.end <= 0) { return 0 }
	const sec = Math.floor((rec.end - rec.start) / 1000)
	return sec > 0 ? sec : 0
}

export function durationHM(sec : number) : string {
	const h = Math.floor(sec / 3600)
	let m = Math.floor((sec % 3600) / 60)
	const mm = m < 10 ? '0' + m.toString() : m.toString()
	return h.toString() + ':' + mm
}
```

### 6.2 本项目简化版

只需要容量 + 标题：

```ts
export type DayMark = {
	date : string
	count : number      // 当天训练条数
	volume : number     // 当天总容量
	title : string      // 容量条下的标题（分类拼接）
}

export function buildMonthMarks(records : TrainRecord[], month : string) : Map<string, DayMark> {
	const map = new Map<string, DayMark>()
	for (let i = 0; i < records.length; i++) {
		const r = records[i]
		if (r.date.length < 7) { continue }
		if (r.date.substring(0, 7) != month) { continue }
		const old = map.get(r.date)
		const vol = recordVolume(r)
		if (old == null) {
			map.set(r.date, {
				date: r.date,
				count: 1,
				volume: vol,
				title: barTitle(r)
			} as DayMark)
		} else {
			const o = old as DayMark
			map.set(r.date, {
				date: r.date,
				count: o.count + 1,
				volume: o.volume + vol,
				title: o.title
			} as DayMark)
		}
	}
	return map
}

/** 取前 3 个不同分类，用 · 连接 */
export function barTitle(rec : TrainRecord) : string {
	const seen : Map<string, boolean> = new Map<string, boolean>()
	const parts : string[] = []
	for (let i = 0; i < rec.moves.length && parts.length < 3; i++) {
		const c = rec.moves[i].category
		if (!seen.has(c)) {
			seen.set(c, true)
			parts.push(c)
		}
	}
	return parts.length > 0 ? parts.join('·') : rec.title
}
```

### 6.3 日历显示规则

| 值 | 显示 |
|---|---|
| `volume > 0` | 蓝色容量条 + 数字 `Math.round(volume)` |
| `count > 0` 但 `volume == 0`（纯有氧/自重） | 蓝色条 + 显示 "1" 或时长 |
| `count == 0` | 不显示条 |

⚠️ 自重动作 `weight = 0` 会导致容量 0，但**训练是存在的**。原版用 `currentWeight`（用户体重）兜底。本项目没存体重，**建议**：容量为 0 但有记录时，条内显示 `count` 而不是 `0`。

## 7. 周统计

训练主页右上角"本周"数字：

```ts
export function weekCount(records : TrainRecord[]) : number {
	const now = new Date()
	const day = now.getDay()                        // 0=周日
	const mondayOffset = day == 0 ? 6 : day - 1     // 周一为一周起点
	const monday = new Date(now.getFullYear(), now.getMonth(), now.getDate() - mondayOffset)
	const startKey = dateKey(monday)
	return records.filter((r) => r.date >= startKey).length
}
```

⚠️ 用字符串比较 `r.date >= startKey` 是安全的，因为格式固定 `YYYY-MM-DD` 且补零。

## 10. 数值精度

所有容量最终都经过 `round1`（保留 1 位小数）。

⚠️ **不要在渲染时再取整**。容量条显示用 `Math.round()` 取整数，但存储和统计用原值。否则多次累加会丢精度。
