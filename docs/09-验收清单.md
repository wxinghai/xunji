1. 用 **HBuilderX → 运行 → 运行到 Android App 基座**（真机）
2. 按 A→B→C→D 顺序逐页走一遍
3. 每完成一张截图，对照本清单打勾
4. E/F 项用真机操作验证，不要只看代码
5. G 项在低端机或模拟器上测
