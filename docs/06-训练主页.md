## 8. 数据流

```
loadRecords()
  ├─ todayRecords = records.filter(r => r.date == todayKey())
  ├─ recent       = records.slice(0, 5)          // 已按日期倒序
  └─ weekCount    = 本周记录数
```

`todayRecords` 映射成卡片数据：

```ts
type TodayCard = {
	id : string
	title : string
	moveCount : number
	setCount : number       // 总组数（不是已完成）
	doneCount : number      // 已完成组数
	percent : number        // Math.floor(doneCount / setCount * 100)
	duration : number       // 秒
}
```

`percent` 计算：

```ts
export function cardPercent(rec : TrainRecord) : number {
	let total = 0
	let done = 0
	for (let i = 0; i < rec.moves.length; i++) {
		const sets = rec.moves[i].sets
		total += sets.length
		for (let j = 0; j < sets.length; j++) {
			if (sets[j].done) { done += 1 }
		}
	}
	if (total == 0) { return 0 }
	return Math.floor(done * 100 / total)
}
```

⚠️ **热身组也计入总数**（原版 `calculatePercent` 未排除 `setType === '热'`）。与容量算法不同，注意别搞混。

## 9. 页面入口

点训练卡 → 打开该记录的编辑器：

```ts
function openTrain(id : string) {
	const rec = findRecord(id)
	if (rec == null) { return }
	saveActive(rec)                       // 存到 xunji_active_v1
	uni.navigateTo({ url: '/pages/session/index' })
}
```

已完成（100%）的记录，点开应该**只读查看**还是**继续编辑**？原版是继续编辑。本项目保持继续编辑。
