## 三条硬约束

1. **不要引入任何 npm 依赖。** 原 App 是 RN + 74 个原生模块，这里全部用 uni-app x 内置能力 + 自己写的 UTS。
2. **数据只存 `uni.setStorageSync`。** 不上 SQLite、不上云同步。原 App 的 20 张表在这里收敛成 2 个 key。
3. **像素级以文档给的数值为准**，不要按"感觉差不多"调。文档里每个数字后面都标了来源模块号。

## 与原 App 的功能取舍

| 原 App | 本项目 | 原因 |
|---|---|---|
| 日历 + 统计双 Tab | 只做日历 | 统计需要大量图表库 |
| 训练中手表联动（7 品牌） | 不做 | 需要原生 SDK |
| 视频讲解（mp4 CDN） | 不做，只留 GIF | APK 内 0 个 mp4 |
| 官方计划 / 30 天周期 | 不做 | 依赖后端 |
| 饮食 / 体重 / 体脂 | 不做 | 超出三 Tab 范围 |
| 模版 / 超级组 | 不做（文档留接口） | 可选扩展 |
| 自定义动作 | 不做 | 可选扩展 |
