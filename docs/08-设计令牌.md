# 08 设计令牌

全部取自 APK 模块 `1744`（主题定义）。**这是唯一权威来源**，不要凭截图取色。

## 1. 主题色

```ts
// 浅色（默认）
THEME_BK          = 'rgb(235,235,235)'   // #EBEBEB  页面背景
THEME_COLOR       = '#007AFF'            // 主题蓝（主色、按钮、选中态）
THEME_COLOR_LIGHT = '#d7e5f8'            // 浅蓝
THEME_BK_LIGHT    = '#F4F4F4'            // 卡片次级底色
THEME_BK_LIGHTER  = 'white'              // #FFFFFF  卡片主底色
Icon_COLOR        = 'rgb(170,170,170)'   // #AAAAAA

// 深色
THEME_BK          = '#28272c'
THEME_COLOR       = '#59b269'            // 深色主题是绿色，不是蓝
THEME_COLOR_LIGHT = '#495c4d'
THEME_BK_LIGHT    = '#333237'
THEME_BK_LIGHTER  = '#46454b'
Icon_COLOR        = 'rgb(120,120,120)'
```

### `T_COLOR(alpha)`

文字色是黑/白加透明度：

```js
T_COLOR(a = 1) => `rgba(0,0,0,${a})`       // 浅色
T_COLOR(a = 1) => `rgba(255,255,255,${a})` // 深色
```

常用值：

| 调用 | 用途 |
|---|---|
| `T_COLOR()` / `T_COLOR(1)` | 主文字 |
| `T_COLOR(0.85)` | 次强调（"今日训练"标题） |
| `T_COLOR(0.8)` | 副标题 |
| `T_COLOR(0.7)` | 说明文字 |
| `T_COLOR(0.65)` | 已完成态 |
| `T_COLOR(0.5)` | 未选中分类 |
| `T_COLOR(0.45)` | 弱提示 |
| `T_COLOR(0.3)` | placeholder |
| `T_COLOR(0.25)` | 极弱 |
| `T_COLOR(0.08)` | 分隔线 |

## 2. 现有项目用的颜色（⚠️ 有偏差）

现项目大量使用 `#F2F2F7` 作为页面背景。**原版是 `#EBEBEB`**。

| 用途 | 现项目 | 原版 | 是否改 |
|---|---|---|---|
| 页面背景 | `#F2F2F7` | `#EBEBEB` | 可选，差异很小 |
| 卡片底色 | `#FFFFFF` | `#FFFFFF` | ✅ 一致 |
| 主色 | `#007AFF` | `#007AFF` | ✅ 一致 |
| 次要文字 | `#8E8E93` | `rgba(0,0,0,0.3~0.5)` | 可选 |

**建议**：`#F2F2F7` 是 iOS 系统分组背景色，比 `#EBEBEB` 更现代、更亮。**保持 `#F2F2F7` 即可**，视觉差异极小，且 `pages.json` 里已经全局设置了。

## 6. 阴影

原版用 `shadowColor/shadowOpacity/shadowRadius/elevation`（RN）。uni-app x **Android 端只支持 `box-shadow`**，改用：

```css
/* 原版 elevation: 3 → */
box-shadow: 0px 2px 3px rgba(0, 0, 0, 0.12);
```

⚠️ uni-app x 的 `box-shadow` 在 Android 上需要 `"uni-app-x": {"vapor": true}` 才生效（项目已开启）。

**建议**：本项目**基本不用阴影**，用 `border` 或底色区分层级更接近现代 iOS 观感，且性能更好。

## 7. uni-app x 样式约束（重要）

从原版 RN 的 `StyleSheet` 迁移时必须注意：

| RN 写法 | uni-app x 写法 |
|---|---|
| `flexDirection: 'row'` | `display: flex; flex-direction: row;`（**必须显式 `display:flex`**） |
| `padding: 8` | `padding: 8px`（**必须带单位**） |
| `fontWeight: 'bold'` | `font-weight: 700;`（用数字更稳） |
| `numberOfLines={1}` | `max-lines="1"` + `text-overflow: ellipsis` |
| `tintColor` | 不支持，用不同图片 |
| `transform: [{rotate:'180deg'}]` | `transform: rotate(180deg);` |
| `StyleSheet.hairlineWidth` | `0.5px` |
| 百分比宽度 `width:'100%'` | `width: 100%;`（支持） |
| `position: 'absolute'` | `position: absolute;`（需在 `display:flex` 内） |

### `<text>` 的限制

- **不能有子 `<view>`**，嵌套必须是 `<text>`
- 换行用 `\n` 或 `max-lines`
- `line-height` 必须写 px 值

### `<view>` 的限制

- 不能直接放文字，必须包 `<text>`
- `border-radius` 单独写 4 个角时要用 `border-top-left-radius` 等

## 8. 暗色模式

`manifest.json` 里目前没有配置暗色。**本项目先不做暗色**，只做浅色。

若要加，在 `pages.json` 里加 `"darkmode": true` 并配 `themeLocation`。但那需要双份样式，工作量大。原版支持暗色，但**不影响功能**。

## 9. 安全区

```css
.status-bar { height: var(--status-bar-height); }
.footer { padding-bottom: calc(10px + env(safe-area-inset-bottom)); }
```

uni-app x 支持 `--status-bar-height` CSS 变量，**不需要** `uni.getSystemInfoSync().statusBarHeight`。

⚠️ 现有项目已经用了 `var(--status-bar-height)`，正确。

## 10. tabBar

`pages.json` 当前配置：

```json
"tabBar": {
	"color": "#8E8E93",
	"selectedColor": "#007AFF",
	"backgroundColor": "#FFFFFF",
	"borderStyle": "black",
	"fontSize": "11px",
	"height": "52px"
}
```

原版 tabBar 是**自定义**的（RN，不是原生 tabBar），高度约 49 + 安全区。当前配置够用。

**注意**：`borderStyle` 只接受 `"black"` / `"white"`，不是颜色值。
